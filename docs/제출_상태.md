## Git 이력과 복제 실습

작업 폴더의 `.git`은 환경 정책으로 쓰기 금지되어 설정·커밋에 실패했습니다. 정상적으로 쓸 수 있는 `outputs/git-history`에 별도의 Git 메타데이터를 보관합니다. 이 경로를 지정해 실제 개발 커밋을 기록했습니다.

```sh
git --git-dir=outputs/git-history --work-tree=. log --oneline --graph --all
```

외부 인증 없이도 검증할 수 있도록 로컬 bare 저장소를 별도 실습 원격으로 사용합니다. 실제 push → 별도 폴더 clone → 복제본 README 수정·commit·push → 원래 작업 폴더 pull 과정은 `evidence/git-practice.txt`에 기록합니다. **이 실습은 GitHub에 대한 clone·push·pull 완료를 의미하지 않습니다.**

전체 커밋·브랜치는 `dist/E1-2-history.bundle`로 보관합니다. 배포 ZIP은 실행 파일과 문서만 포함하며, Git 이력은 별도 bundle에 담습니다. 일반 환경에서는 bundle로 저장소를 복원할 수 있습니다.

```sh
git clone E1-2-history.bundle E1-2
cd E1-2
python main.py
```

## 완료하지 못한 항목

- **GitHub 저장소 생성 및 업로드:** 요청 대상은 `https://github.com/llcckk9935/E1-2`입니다. 연결 도구 조회는 404를 반환했고 도구에 저장소 생성 기능이 없습니다. 로컬 Git 인증 정보도 사용할 수 없었습니다. 실제 원격 push 결과는 `evidence/github-upload.txt`에 별도로 기록합니다.
- **실제 화면 스크린샷:** 브라우저 현재 URL을 충분히 확인할 수 없다는 Computer Use 안전 제한으로 UI 접근이 중단됐습니다. 추가 UI 자동화를 하지 않았으며 환경·게임·Git 그래프의 스크린샷을 촬영했다고 기록하지 않습니다. 제공된 텍스트 실행 기록은 스크린샷을 대체하는 제출 완료 증거가 아닙니다.
- **교육 플랫폼 제출:** 이번 요청은 지정 GitHub 저장이며 별도 플랫폼 제출은 수행하지 않았습니다.

따라서 프로그램 구현과 로컬 제출 준비는 완료했지만, **GitHub 저장 및 최종 제출 완료 상태는 아닙니다.**
