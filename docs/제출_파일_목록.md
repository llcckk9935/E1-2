# 제출 파일 구분

이 폴더 전체를 업로드하지 않습니다. Git에 명시적으로 등록한 아래 파일만 제출 대상으로 삼습니다.

## 업로드 제외

- 개인 시험 답안지 `.md`·`.html`과 `개인학습_필수완성예시/`.
- 기존 개인 복습 노트, 과제 원본, 과제 도우미 지침서.
- 실행 중 생성되는 `state.json`, 손상 파일 보관본, 임시 저장 파일.
- `__pycache__/`, Python 캐시, `.venv/`.
- `outputs/`의 작업용 코드·복제본·Git 메타데이터.
- `dist/`의 ZIP·bundle 등 로컬 배포 사본.
- `tools/`의 자료 생성용 작업 스크립트.
- 로컬 제출 준비 상태와 업로드 실패 진단 기록.

실행 데이터는 첫 실행과 정상 종료 시 프로젝트 루트에 생성됩니다. 개인 퀴즈나 점수 기록을 GitHub에 공개하지 않기 위해 예제 파일과 분리합니다.

`git ls-files`는 실제 등록된 파일만 표시합니다. `git add .`로 폴더 전체를 등록하지 않고 필요한 파일 경로를 지정해 기록합니다.
