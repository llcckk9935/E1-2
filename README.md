# 기초 상식 퀴즈 게임 — E1-2

Python 기본 문법과 클래스로 구현한 콘솔 퀴즈 게임입니다. 메뉴에서 퀴즈 풀기·등록·목록·점수·삭제·기록을 선택하고 종료 후에도 퀴즈와 점수를 유지합니다. 필수 기능과 선택 과제 5개를 모두 구현했습니다.

## 주제와 선정 이유

학습 중 사용자가 선택한 **기초 상식**을 주제로 삼았습니다. 익숙한 문제로 전문 지식 조사 부담을 줄이고 Python과 Git 학습에 집중합니다. 기본 문제는 일주일의 일수·삼각형의 변·지구의 위성·얼음·대한민국의 수도입니다.

도우미가 구현과 검증을 수행했습니다. 이 이력은 사용자가 직접 작성했다는 뜻이 아닙니다. [코드 읽기 안내서](docs/코드_읽기_안내서.md)로 완성 코드를 공부할 수 있습니다.

## 실행 방법

Python **3.10 이상**과 표준 라이브러리만 사용합니다. 추가 설치 패키지는 없습니다. 현재 폴더 또는 제출 ZIP을 푼 폴더에서 실행합니다.

```sh
python main.py
```

Windows에서 `python` 대신 Python 런처가 설치되어 있으면 `py -3 main.py`를 사용합니다. 한글 출력에 문제가 있으면 `python -X utf8 main.py`로 실행합니다.

GitHub 업로드가 완료된 환경에서는 다음과 같이 복제할 수 있습니다.

```sh
git clone https://github.com/llcckk9935/E1-2.git
cd E1-2
python main.py
```

> 원격 저장소 생성·업로드와 화면 캡처의 실제 완료 여부는 [제출 상태](docs/제출_상태.md)를 확인하세요. 로컬 구현 완료와 GitHub 저장 완료를 구분했습니다.

## 기능 목록

| 번호 | 기능 | 동작 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 문제 수 선택, 중복 없는 무작위 출제, 정오답·결과 표시 |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호·힌트를 입력하고 저장 |
| 3 | 퀴즈 목록 | 등록된 문제 제목과 개수 표시 |
| 4 | 점수 확인 | 완료한 게임의 최고 점수, 미플레이 상태 안내 |
| 5 | 종료 | 저장 시도 후 종료 |
| 6 | 퀴즈 삭제 | 번호 선택, 확인 또는 취소, 삭제 결과 저장 |
| 7 | 게임 기록 | 날짜·시간, 선택 문제 수, 응답 수, 정답 수, 힌트 수, 점수, 완료 여부 |

입력 앞뒤 공백은 제거합니다. 빈 입력, 문자, 범위 밖 숫자는 안내 후 다시 입력받습니다. 정답은 1~4이며 **풀이 화면에서만 0은 힌트**입니다. 삭제 화면의 0은 취소입니다. 등록 정답 0은 허용하지 않습니다. 모든 문제를 삭제하면 풀기·목록·삭제에 빈 상태 안내가 나오며 재실행해도 빈 목록이 유지됩니다.

## 점수와 중간 종료 규칙

```python
score = max(0, round(correct / total * 100) - hints_used * 10)
```

- `total`은 선택한 문제 수입니다. 정답 비율을 100점 기준으로 계산한 뒤 힌트를 본 문제당 10점 차감합니다.
- 같은 문제의 힌트를 여러 번 보아도 한 번만 차감하며 점수는 0점 아래로 내려가지 않습니다.
- 5문제 중 4개 정답, 힌트 1회이면 70점입니다. 반올림은 Python `round()` 규칙을 따릅니다.
- 최고 점수는 끝까지 완료한 게임만 비교합니다. 첫 완료가 0점이면 최고 점수도 0점입니다. 미플레이 상태는 `null`입니다.
- Ctrl+C 또는 입력 종료(EOF) 시 진행 중 게임을 중단 기록으로 저장하고 종료합니다. 중단 점수도 선택한 전체 문제 수를 분모로 계산하며 최고 점수에는 반영하지 않습니다.
- 문제 수 선택 전 종료하면 게임 기록은 생성하지 않습니다. 등록 중 종료하면 미완성 문제는 추가하지 않습니다.

## 데이터 파일

`state.json`은 **main.py가 있는 프로젝트 루트**에 UTF-8로 저장합니다. 다른 폴더에서 절대 경로로 실행해도 저장 위치는 같습니다. 개인 플레이 기록은 Git에서 제외하고 예제만 포함합니다.

```json
{
  "quizzes": [
    {
      "question": "대한민국의 수도는 어디일까요?",
      "choices": ["서울", "부산", "대전", "광주"],
      "answer": 1,
      "hint": "한강과 경복궁이 있는 도시입니다."
    }
  ],
  "best_score": 90,
  "history": [
    {
      "date": "2026-11-22T12:00:00+09:00",
      "total": 1,
      "answered": 1,
      "correct": 1,
      "hints_used": 1,
      "score": 90,
      "completed": true
    }
  ]
}
```

위 날짜와 점수는 형식 설명용 예시입니다.
`best_score`는 미플레이 시 `null`, `history`는 기록이 없으면 `[]`입니다. `date`는 현지 시각과 UTC 시차를 포함합니다. 이전 필수 기능 형식처럼 `hint`나 `history`가 없으면 기본 힌트와 빈 기록으로 읽습니다.

파일이 없으면 기본 퀴즈로 시작합니다. JSON 문법·인코딩·필드 타입·정답 범위·기록 데이터가 잘못되면 원본을 `state.json.corrupt-날짜-시간`으로 보관하고 기본 데이터로 시작합니다. 손상 파일 보관 실패나 읽기 권한 오류가 나면 원본 보호를 위해 해당 실행의 저장을 막습니다.

임시 파일을 완성한 뒤 교체하여 저장 도중 실패해도 기존 파일을 보호합니다. 쓰기 실패는 메시지로 알리고 메모리에만 유지하므로 **저장 실패 시 종료 후 변경 유지가 보장되지 않습니다**. 여러 게임 프로세스를 동시에 실행하는 용도는 지원하지 않습니다.
